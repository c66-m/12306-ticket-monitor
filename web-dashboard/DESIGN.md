# Design

<!-- impeccable:design-schema 1 -->

**视觉方向**：浅色玻璃拟态 × 弥散悬浮分层的车票监控控制台。全域零实线边框，模块边界由阴影深度、底色色差和玻璃材质共同承担；层级越高，投影越深、玻璃越透。

参考锚点：浅色玻璃拟态仪表盘概念图（紫蓝横幅 + 悬浮侧栏 + 白色内容卡）。参考图是方向证据，不是逐像素复刻目标。

### 1.3 阴影 — 弥散分层（核心）

层级只由这四级投影表达，**任何地方都不允许出现实线边框**。

| 令牌 | 值（浅色） | 对应层级 |
|---|---|---|
| `--sh-1` | `0 2px 6px -2px rgb(24 32 53/.06)` | 行、徽章、内联小件 |
| `--sh-2` | `0 14px 34px -14px rgb(24 32 53/.18), 0 2px 8px -3px rgb(24 32 53/.08)` | 功能模块卡 |
| `--sh-3` | `0 28px 64px -24px rgb(24 32 53/.30), 0 6px 18px -8px rgb(24 32 53/.12)` | 焦点横幅、侧边栏 |
| `--sh-4` | `0 40px 84px -28px rgb(24 32 53/.36), 0 10px 26px -10px rgb(24 32 53/.16)` | 浮起态（悬停、下拉） |

阴影必须带**偏移**与**柔化半径**。零偏移的彩色光晕属于装饰，禁止。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-xl` | `32px` | 侧边栏、焦点横幅、主模块卡 |
| `--r-lg` | `22px` | 卡内分组、图片格 |
| `--r-md` | `14px` | 按钮、列表行、输入 |
| `--r-sm` | `10px` | 徽章、标签 |
| `--r-pill` | `999px` | 胶囊按钮、搜索圆钮 |

### 1.5 间距与栅格

- 模块间距 `--gap: 20px`；卡内边距 `--pad: 22px`。
- 组内间距 10–14px，组间 20–24px；**标题上方的留白大于下方**。
- 主内容区左右两列：`minmax(0,1.62fr) minmax(0,1fr)`，窄屏折为单列。

### 1.6 字体

```
--font: -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei UI", system-ui, sans-serif
--mono: "SF Mono", "Cascadia Mono", Consolas, ui-monospace, monospace
```

- 固定 rem 阶梯，不做流体字号。正文 14px / 行高 1.6，卡片标题 15px/600，横幅标题 30px/650。
- 字号比约 1.14–1.2。
- 车次号、时刻、倒计时、计数用 `--mono` 并开 `font-variant-numeric: tabular-nums`。
- 正文行宽 65–75ch。

## 2. 材质规则

1. **玻璃只用在承担分层职责的容器上**：侧边栏、焦点横幅、功能模块卡、底部记录栏。装饰性模糊不做。
2. 每块玻璃 = `backdrop-filter: blur(22px) saturate(150%)` + 半透明底 + 上缘 1px `inset` 微高光。
3. **禁止嵌套玻璃**：主内容区不套大卡，各模块**平级**排布——这是分层，不是分组。
4. 长文本区若有可读性风险，改用 `--glass-strong`，不靠加边框解决。

---

## 3. 层级顺序

侧边栏 > 焦点横幅 > 功能模块卡 > 页面背景。投影深度严格按此顺序递进（`--sh-3` > `--sh-3` > `--sh-2` > 无）。

---

## 4. 布局结构

```
[ 悬浮侧边栏 ]  [        焦点横幅卡（通栏）        ]
[  固定 248px ] [ 信息流列表          快捷条目列表  ]
[            ] [ 车次快照瀑布流       环形数据统计  ]
[================= 底部横向操作记录栏 ==============]
```

- 侧边栏独立悬浮、全局层级最高，四周留出 18px 呼吸位。
- 底部记录栏贯穿内容区全宽，同一玻璃材质，`--r-xl`。
- 窄屏（<1080px）侧栏折为图标轨；窄屏（<820px）单列堆叠。

---

## 5. 组件规范

- **导航项**：默认透明；悬停 `--glass-strong`；选中 = `--glass-strong` 底 + 右缘 3px 圆角指示条（**独立元素**，不是 `border-right`），条色按分组轮转 accent / cyan / pink / amber。
- **按钮**：主操作 = accent 实底 + 白字；次操作 = `--glass-strong` + ink；幽灵 = 透明 + ink-2。全部 `--r-md` 或 pill。**同一动作在全页只有一种样子。**
- **状态徽章**：`--r-sm` 胶囊，底色 = 状态色 12% 透明，文字 = 状态色加深。语义固定：监控中=accent、已暂停=neutral、今日任务=amber、已抢到=success、失败=danger。
- **图标**：全部手写内联 SVG，统一 1.6px 描边、圆头圆角、24×24 视框。**不用 emoji，不用字体图标。**
- **环形统计**：必须有真实数值、单位与图例标签，禁止当成装饰性圆环。
- **输入/下拉**：`--glass-strong` 底 + `--r-md`，聚焦时外圈 `0 0 0 3px color-mix(in srgb, var(--accent) 28%, transparent)`。

**交互态**：每个可交互元素必须有 default / hover / focus-visible / active / disabled 五态。过渡 160–220ms。

---

## 6. 浏览器表面

选中文字（`::selection`）、输入光标（`caret-color`）、滚动条、焦点环（`:focus-visible`）、下划线偏移、表格数字（`tabular-nums`）都从本套令牌取值。这些是"被建造过"与"被拼装过"的分界线。

---

## 7. 禁止项

- 任何实线边框（`border: 1px solid`）承担分区职责。
- 嵌套卡片：卡里再套整块卡。
- 渐变文字。
- 零偏移彩色光晕。
- 标题上方的小字 kicker / eyebrow 标签。
- 用 emoji 或 Unicode 字符充当图标。
- 装饰性动画；页面载入编排动画。
- 重型满饱和强调色出现在非活跃状态上。

---

## 8. 验收

双主题下渲染一致；正文对比度 ≥ 4.5:1；键盘可遍历全部控件且焦点可见；`prefers-reduced-motion` 下动效退化为无位移；无任何网络请求；无第三方依赖。
